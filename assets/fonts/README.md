# Bundled fonts

| Family | Files | Licence | Used for |
|---|---|---|---|
| Liberation Sans / Serif / Mono 2.1.5 | `liberation/*.ttf` | SIL OFL 1.1 (`liberation/LICENSE`) | Text added or substituted by the editor; metric-compatible with Arial / Times New Roman / Courier New (SPEC §8.7) |

Source: https://github.com/liberationfonts/liberation-fonts (Debian/Ubuntu package `fonts-liberation`).
Fonts are loaded on demand by the engine (`FontRegistry`), never fetched from the network.
