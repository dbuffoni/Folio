# Building and testing

Reference platform: Ubuntu 22.04 or newer, x86_64.

## Toolchain

| Tool | Version | Used for |
| --- | --- | --- |
| Node.js | 22.13 or newer | everything in TypeScript (`node:sqlite` is used by tests) |
| pnpm | 10 (pinned in `package.json`) | workspace |
| Rust | stable, with clippy and rustfmt | desktop shell |
| qpdf, poppler-utils, mupdf-tools, pdfcpu | any recent | test oracles |

```bash
sudo apt install qpdf poppler-utils mupdf-tools
# pdfcpu: download the release binary from github.com/pdfcpu/pdfcpu and put it on PATH
pnpm install
```

## Web

```bash
pnpm dev      # development server
pnpm build    # static site in apps/web/build
```

The PDF engine, its WASM file and the bundled fonts are copied into the build; nothing is loaded
from another origin.

## Desktop (AppImage)

```bash
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev \
  libsecret-1-dev patchelf file
pnpm appimage           # builds the web UI, then the Tauri bundle
```

The AppImage is written to `apps/desktop/src-tauri/target/release/bundle/appimage/`.
`pnpm tauri dev` starts the shell against the development server.

### Smoke test

```bash
sudo apt install xvfb dbus-x11 gnome-keyring webkit2gtk-driver
cargo install tauri-driver --locked
pnpm appimage:smoke
```

It unpacks the AppImage (so it also works where FUSE is unavailable), starts it under Xvfb with a
PDF as argument and checks start-up, the file association, scoped file access, an atomic save and a
rotate-and-save flow through the real screens.

## Tests

```bash
pnpm lint && pnpm check          # ESLint, dependency rules, migrations, i18n lint, tsc, svelte-check
pnpm coverage                    # unit + conformance with coverage thresholds
pnpm test:interop && pnpm bench  # oracles, golden images, performance budgets
pnpm --filter @folio/web exec playwright install --with-deps chromium firefox webkit
pnpm test:e2e                    # builds the web app and runs the browser suites
pnpm gate P9                     # everything, as the release gate
```

Fixtures are generated by code (`pnpm fixtures:build` writes them to `fixtures/generated` for
inspection); none are committed. Third-party samples would be listed in `fixtures/manifest.json`
and fetched with `pnpm fixtures:fetch`.

### Baselines

- Engine golden images live in `tests/golden/baselines`. After an intended rendering change run
  `pnpm test:golden:update` and review the PNG diff.
- UI screenshots live next to `apps/web/tests/visual.spec.ts`. They depend on the fonts of the
  machine that rendered them; update with `pnpm test:e2e --update-snapshots` on the reference
  machine. CI does not compare them.

## Release

Pushing a tag `v*` runs `.github/workflows/release.yml`: build, smoke test, checksums, SBOM and a
draft GitHub release. The AppImage is not signed yet (see docs/PROGRESS.md).
